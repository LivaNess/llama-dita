2. Estándares y Protocolos Abiertos

Llamadita utiliza exclusivamente protocolos y APIs estandarizadas por la W3C y el IETF, garantizando interoperabilidad, seguridad y privacidad técnica:

  • WebRTC (Web Real-Time Communication): Transporte seguro y directo punto a punto (P2P) de flujos de audio de ultra baja latencia con códec Opus mediante cifrado DTLS-SRTP.
  • Web Audio API: Procesamiento de audio acústico en el cliente (cancelación de eco, control automático de ganancia, supresión de ruido y vúmetro estéreo).
  • Web Cryptography API (SubtleCrypto): Cifrado de alto rendimiento en el cliente para tokens de acceso y operaciones criptográficas seguras.
